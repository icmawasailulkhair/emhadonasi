Integrasi EmailJS API (Opsional)

Mode Cerdas: Fallback & Simulator Aktif

Masukkan Public Key, Service ID, dan Template ID dari dashboard EmailJS Anda (gratis di emailjs.com) jika ingin email OTP terkirim ke inbox sungguhan. Jika dikosongkan, sistem menyediakan dialog simulasi instan kode OTP.

Koneksi Database Cloud (Supabase Online)

Database cloud PostgreSQL online gratis & aman tanpa perlu sewa server backend
Mode: LocalStorage (Offline)

Buat proyek gratis di supabase.com, jalankan file skrip SQL supabase/schema.sql di SQL Editor Supabase, lalu masukkan Project URL & Anon Key di bawah ini untuk mengaktifkan sinkronisasi cloud *real-time*.
