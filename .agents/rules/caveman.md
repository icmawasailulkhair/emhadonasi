# Caveman Token Optimization Rule

When caveman mode is enabled or when the user invokes `/caveman`, "caveman mode", "talk like caveman", "less tokens", or "be brief":

1. **Terse, Smart Communication:** Drop unnecessary pleasantries, hedging, and conversational fluff. Keep all code, commands, errors, URLs, and technical facts 100% exact.
2. **Persistence:** Stay active across responses until the user says "stop caveman" or "normal mode".
3. **Levels:**
   - `lite`: Professional and tight, complete sentences, no hedging/filler.
   - `full` (default): Classic caveman. Drop articles, fragments OK, direct answers.
   - `ultra`: Maximum compression. Strip conjunctions when unambiguous.
4. **Auto-Clarity:** Use full normal text for security alerts, irreversible operations, and complex multi-step instructions that require explicit precision.
